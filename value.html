Card data and pricing come from the community-run Pokémon TCG API with market prices from TCGplayer; prices move constantly and condition changes everything — treat these as ballpark figures for near-mint copies. PokéSpa is not affiliated with TCGplayer or the Pokémon TCG API and earns nothing from this tool. A graded, damaged, or restored copy is worth a different number — and a restored card must always be sold as restored.

Restoration is disclosed and honest — never to deceive a grader or buyer.
